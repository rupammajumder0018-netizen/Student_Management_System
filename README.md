# 🎓 Student Management System

A console-based **Student Management System** built with Python using Object-Oriented Programming (OOP), CRUD operations, input validation, and JSON-based data persistence.

This project allows users to manage student records through a simple command-line interface while keeping student data saved between program executions.

---

## 📌 Features

- ➕ Add new students
- 🔍 Search students by roll number
- ✏️ Update student marks
- 🗑️ Delete student records
- 📋 Display all students
- 📊 View student statistics
- 🎓 Calculate student grades
- ✅ Input validation
- 🔢 Unique roll-number validation
- 💾 Persistent data storage using JSON
- 🛡️ JSON error handling
- 🧩 Modular project structure
